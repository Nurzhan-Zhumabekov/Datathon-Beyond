# Signal Hunter

Одна команда превращает таблицу в заготовку истории для жюри: аудит утечек, честная валидация,
сегменты и взаимодействия с проверкой на двух половинах данных, слепые зоны модели, ценность решения в деньгах.
Всё готовится за пару минут, а время дататона уходит на мышление.

## Запуск

Один раз на каждом ноутбуке (нужен [uv](https://docs.astral.sh/uv/), он сам поставит Python 3.12):

```bash
uv sync
```

Проверить на демо-данных с заложенными находками (около 30 секунд):

```bash
uv run python examples/make_demo_data.py
uv run python -m signalhunter examples/demo_train.csv --target churn --test examples/demo_test.csv --id-cols client_id --out out_demo
```

Открыть `out_demo/report.md`. Графики для слайдов лежат в `out_demo/charts/`.

## На дататоне

```bash
uv run python -m signalhunter data/train.csv --target ЦЕЛЬ --test data/test.csv --id-cols id --out out
```

| Флаг | Когда нужен |
|---|---|
| `--time-col дата` | Если test из будущего. Модель обучается на прошлом и проверяется на будущем. **Почти всегда нужен, если есть даты.** |
| `--group-col клиент` | Если у одного клиента несколько строк. Иначе метрика завышена. |
| `--id-cols a,b` / `--drop a,b` | Идентификаторы и колонки, которые надо игнорировать |
| `--positive значение` | Какой класс считать целевым (мультикласс сводится к «этот против остальных») |
| `--gain-tp 500000 --cost-fp 3000` | **Реальные** ценность найденного случая и цена лишнего действия. По умолчанию 10 и 1, это заглушки |
| `--keep-leaky` | Не исключать колонки с критичной утечкой |
| `--fast` | Первая быстрая прогонка на больших данных |

## Что в `out/`

- `report.md` — отчёт с готовыми формулировками для слайдов
- `charts/` — графики 16:9 с заголовками-выводами
- `segments.csv`, `blind_spots.csv`, `leakage.csv`, `profile.csv`, `lift.csv` — таблицы
- `predictions_test.csv` — baseline-предсказания для test (если передан `--test`)
- `summary.json` — ключевые числа

## Как читать результат

- **Утечки.** `critical` исключается из модели автоматически. Прежде чем радоваться метрике, выясните у организаторов, когда заполняется эта колонка.
- **Группы и взаимодействия.** `stable = да` означает, что эффект подтвердился в обеих половинах данных (или в старой и новой, если задан `--time-col`). Показывайте жюри только такие. «Взаимодействие» означает, что вместе условия дают заметно больше, чем сумма их отдельных эффектов.
- **Слепые зоны.** Сегменты, где модель систематически занижает или завышает. Это основа слайда про ограничения.
- **Ценность решения.** Чистая ценность по лучшему порогу. Цифры верны ровно настолько, насколько верны `--gain-tp` и `--cost-fp`.

## Ограничения (скажите жюри честно)

- Это baseline и генератор гипотез, а не готовый ответ. Находки надо осмыслить и проверить на здравый смысл.
- Текст и изображения в baseline не используются. Временные ряды учитываются только через `--time-col` и признаки даты.
- Порог в разделе «ценность» подбирается на тех же out-of-fold предсказаниях, поэтому оценка слегка оптимистична.
